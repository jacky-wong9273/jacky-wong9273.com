## The Joy of Teaching

Tutoring IB Computer Science has been one of the most rewarding experiences of my career. There's something magical about the moment a student's eyes light up when they finally understand recursion or grasp why abstraction matters.

## Common Student Misconceptions

After years of tutoring, I've noticed patterns in what trips students up:

### 1. "Arrays and Linked Lists Are the Same Thing"

Students often conflate these because both store collections. I use a restaurant analogy:

- **Array** = reserved table seating (fixed, contiguous positions)
- **Linked list** = a treasure hunt where each clue points to the next

### 2. Confusing Recursion with Iteration

The key insight: recursion is about _trusting the function to handle the smaller problem_. I use the Russian nesting dolls analogy — each doll opens to reveal a smaller version of itself.

### 3. Big O Notation Anxiety

Students see O(n²) and panic. I frame it as a _cost estimate_:

| Algorithm | Analogy                                          |
| --------- | ------------------------------------------------ |
| O(1)      | Flipping a light switch                          |
| O(log n)  | Looking up a word in a dictionary                |
| O(n)      | Reading every page of a book                     |
| O(n²)     | Comparing every student with every other student |

## Tips for IB CS Educators

1. **Use analogies relentlessly** — abstract concepts need concrete metaphors
2. **Trace code by hand** — make students be the computer
3. **Connect to real life** — databases power Instagram, algorithms power Google
4. **Encourage failure** — debugging is where the real learning happens
