## Overview

This is my personal portfolio website — the very site you're looking at right now! It's built with [Astro](https://astro.build) and uses MDX for content authoring, making it easy to update without touching any framework code.

## Tech Stack

- **Framework:** Astro with static output
- **Content:** MDX for rich, component-enhanced Markdown
- **Language:** TypeScript (strict mode)
- **Hosting:** Backblaze B2 object storage + Cloudflare CDN
- **Styling:** Vanilla CSS with custom properties

## Key Features

1. **Static output** — zero JavaScript by default, instant page loads
2. **MDX content** — update content in any Markdown editor
3. **Responsive design** — works seamlessly on all devices
4. **Dark theme** — easy on the eyes

## What I Learned

Building this site reinforced the value of simplicity. By going fully static with Astro, the site loads instantly and costs virtually nothing to host.

> The best website is the one that's actually published.
