## Stacks

A **stack** is a Last-In-First-Out (LIFO) data structure. Think of it like a stack of plates — you can only add or remove from the top.

### Core Operations

- `push(item)` — Add an item to the top
- `pop()` — Remove and return the top item
- `peek()` — View the top item without removing it
- `isEmpty()` — Check if the stack is empty

### Pseudocode Implementation

```
class Stack
  private items = []
  private top = -1

  method push(item)
    top = top + 1
    items[top] = item
  end method

  method pop()
    if isEmpty() then
      return ERROR
    end if
    item = items[top]
    top = top - 1
    return item
  end method

  method isEmpty()
    return top == -1
  end method
end class
```

## Queues

A **queue** is a First-In-First-Out (FIFO) data structure. Like a line at a shop — first person in line is served first.

### Core Operations

- `enqueue(item)` — Add an item to the rear
- `dequeue()` — Remove and return the front item
- `peek()` — View the front item
- `isEmpty()` — Check if empty

## IB Exam Tips

1. Always state the **type** of data structure and its **access pattern** (LIFO/FIFO).
2. Draw diagrams showing the state of the structure after each operation.
3. Be prepared to **trace** through push/pop or enqueue/dequeue sequences.

Trace the stack and write the output at each step.
